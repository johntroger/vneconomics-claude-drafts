# vneconomics-claude-drafts

Kho lưu bản nháp nội dung do Claude Code chuẩn bị cho store.vneconomics.com. Chỉ là bản nháp: chưa import, chưa xuất bản. Codex hoặc chủ site lấy về, rà soát rồi mới đưa vào pipeline phát hành của dự án `vneconomics-store`.

- Claude Code chỉ thêm file vào `content-drafts/`.
- Mỗi thư mục con có `content.json`, `research/` và `README.vi.md` ghi repo, license, điểm chưa chắc chắn.

## Bắt đầu từ đâu
- `catalog/INDEX.vi.md`: mục lục tổng theo độ khó và theo lộ trình học.
- `catalog/learning-paths/`: 15 lộ trình học (bắt đầu, vibe code có kỷ luật, đưa website chạy thật, đọc hiểu mã web AI dựng, làm quen terminal, dữ liệu có AI hỗ trợ, hiểu AI và LLM, tạo website nội dung, bảo mật tối thiểu, cho AI đọc web, tự động hóa).
- `catalog/catalog.json`: dữ liệu máy đọc được (độ khó, bài liên quan).
